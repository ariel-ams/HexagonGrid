# Pre-Lamp-Style Vine Backup

This immutable batch preserves `assets/vines-alpha.png` from before the Vine Lamp-style migration on 2026-08-14.

Restore from the repository root with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File assets/sprite-backups/pre-lamp-style-vine-2026-08-14/restore.ps1
```

Run `npm test` after restoring.

# Runtime Sprite Backups

Each directory here preserves the exact runtime sprite files used before a coordinated art migration. Backups mirror paths relative to the repository root so restoration stays explicit and reviewable.

- `pre-lamp-style-2026-08-14/`: ten core first-run sprites used before the Lamp-style migration.

Open a backup directory's `README.md` before restoring. Never edit files inside a dated backup; create another migration directory instead.

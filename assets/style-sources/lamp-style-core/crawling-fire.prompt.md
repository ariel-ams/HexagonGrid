# Crawling Fire ImageGen Prompt

Reference: `assets/items/lamp-cell.png`. Mode: built-in ImageGen.

The initial generation made the idle row look like a campfire. The retained `crawling-fire-imagegen-v1.png` records that attempt. The accepted revision redraws the same `4 x 3` sheet as a chunky low ember salamander/bug in every row: row 1 default idle, row 2 modest rightward crawl, row 3 water splash and extinguish. It keeps a large glowing core body, short molten claws, low flame ridge, dark smoke tip, consistent size and anchor, strong outline, and 64-96 px readability. It excludes tall campfires, logs, floors, hex tiles, labels, borders, scenery, and extra creatures.

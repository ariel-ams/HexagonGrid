# Scenario Routing Map for UI Files

Use this map to decide which docs the agent must read before finalizing a task.

## Always read

- [agent-process.md](./agent-process.md)
- [pr-oracle-template.md](./pr-oracle-template.md)

## Scenario matrix

1. New flow / navigation / architecture change
   - `agent-process.md`
   - `pr-oracle-template.md`
2. Interaction behavior change (buttons, forms, state, validation, error handling)
   - `agent-process.md`
   - `pr-oracle-template.md`
3. Copy/interface text changes (labels, microcopy, onboarding, hints)
   - `agent-process.md`
   - `pr-oracle-template.md`
4. Visual style/layout spacing/touch target adjustments
   - `agent-process.md`
   - `pr-oracle-template.md`
5. Accessibility, readability, keyboard-flow, focus changes
   - `agent-process.md`
   - `pr-oracle-template.md`

If no single scenario fits, read all three docs.

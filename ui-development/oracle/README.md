# UI Development Documentation

This directory defines how the Codex agent applies UX-oracle rules for all UI-related work.

## Use this in this order

1. [agent-process.md](./agent-process.md)
   - Required for every UI task.
2. [routing-map.md](./routing-map.md)
   - Choose which specialized docs apply to the current task shape.
3. [pr-oracle-template.md](./pr-oracle-template.md)
   - Paste-ready blocks for PR description or commit notes.

## Quick rule

- The agent must treat any task that affects UI/UX behavior as a UI task unless explicitly excluded.
- If uncertain, default to UI rules.
# Expanded operating docs

Read `project-usage-guide.md` when adopting this system in a repository. Read `trust-and-trends-roadmap.md` when planning, reviewing, or evolving UI work. The routing map remains the starting point for individual tasks.
